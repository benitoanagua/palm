# @palm/icons

PALM uses **Tabler Icons exclusively**.

The public API is intentionally minimal. Components consume `pm-icon` with a Tabler icon name. No provider abstraction, aliases, fallback collections, or alternate icon families are supported.

```html
<pm-icon name="search"></pm-icon>
```

The dataset is generated at build time from `@tabler/icons` (MIT License). See [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md) for full licensing and attribution details.
