# Component Workflow

1. Define the component contract before implementation.
2. Add or refine tokens before hard-coding visual values.
3. Implement with Stencil and semantic HTML.
4. Prefer slots over stringly-typed content APIs.
5. Add typed custom events only for application-observable behavior.
6. Test keyboard and accessibility behavior.
7. Add Cosmos fixtures for variants and states.
8. Document the public API.
9. Add a Changeset when the public package changes.
