# PALM documentation

PALM is an independent design system implemented with Stencil and Web Components.

STRATA is referenced only for repository-organization ideas. No STRATA visual language, tokens, component logic, APIs, or behavior are inherited.

Documentation areas:
- architecture
- foundations
- components
- accessibility
- visual regression
- framework integrations

## Showcase

The repository includes `apps/showcase`, a small product-like surface built exclusively from PALM Web Components. It is the reference application for composition, responsive behavior, forms, navigation, overlays, themes and visual consistency.
