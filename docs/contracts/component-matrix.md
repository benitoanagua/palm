# Initial Component Matrix

| Component | Category | Primary semantic | Slots | Events |
|---|---|---|---|---|
| `pm-icon` | primitive | image/decorative icon | none | none |
| `pm-button` | action | button | start, default, end | `pmPress` |
| `pm-icon-button` | action | button | none | `pmPress` |
| `pm-input` | form | input | none | `pmInput` |
| `pm-textarea` | form | textarea | none | `pmInput` |
| `pm-checkbox` | form | checkbox | none | `pmChange` |
| `pm-radio` | form | radio | none | `pmChange` |
| `pm-switch` | form | switch | none | `pmChange` |
| `pm-select` | form | select | default | `pmChange` |
| `pm-card` | content | article | header, default, footer | none |
| `pm-badge` | feedback | status | default | none |

This matrix is a PALM contract and is not derived from STRATA APIs.
